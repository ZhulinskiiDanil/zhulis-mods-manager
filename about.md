# Zhulis Mods Manager

Installs and updates **Zhulis** mods straight from their GitHub releases, even before a new version is accepted on the Geode Index.

- Open **Geode → Mods** and press the GitHub button on the left to see all Zhulis mods
- Mods with a newer GitHub release get a **GitHub vX** label and an update button in their popup
- Checks for updates on startup (can be disabled in settings)

Tracked mods: Blitzkrieg, AskDash
